# Diyabet Tahmini | Diabetes Prediction

[Notebook](notebook.ipynb) · [Kaggle](https://www.kaggle.com/code/enesfurkanmacit/diabetes-prediction-catboost-lightbgbm-0-7265)

## Türkçe

Sağlık göstergeleri içeren yarışma verisinde keşifsel veri analizi, kategorik değişken kontrolleri ve CatBoost ile LightGBM sınıflandırma modelleri yer alır. Notebook, doğrulama kümesinde AUC ve ROC eğrisi ile model değerlendirmesini içerir; başlıkta yer alan 0,7265 değeri notebookta LightGBM sonucu olarak belirtilmiştir.

Bu çalışma eğitim ve modelleme amaçlıdır; klinik tanı veya tıbbi karar verme amacıyla doğrulanmış bir araç değildir.

## English

An exploratory analysis and classification exercise on competition data containing health indicators. The notebook checks categorical features, trains CatBoost and LightGBM models, and evaluates them using AUC and ROC curves. The 0.7265 value in the title is identified in the notebook as a LightGBM result.

This is an educational modelling exercise, not a validated clinical or diagnostic tool.

## Çalıştırma / Reproduction

Use Python with pandas, NumPy, scikit-learn, CatBoost, LightGBM and the visualization libraries imported in the notebook. Obtain the datasets from the [Kaggle notebook](https://www.kaggle.com/code/enesfurkanmacit/diabetes-prediction-catboost-lightbgbm-0-7265) and adjust the input paths before running locally.
